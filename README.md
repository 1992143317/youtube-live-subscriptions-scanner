# YouTube Live Subscriptions Scanner

A Tampermonkey userscript that scans your YouTube subscriptions and lists channels that are currently live.

## Features

- Detects live streams from subscribed channels
- Displays channel name, title and viewer count
- Draggable panel
- Collapsible panel
- Real-time scanning
- Fast parallel scanning

## Installation

Install via GreasyFork:

https://greasyfork.org/scripts/569042

Or install manually:

1. Install Tampermonkey
2. Open the .user.js file
3. Click install

## Usage

Open the YouTube homepage:

https://www.youtube.com/

The script will automatically scan your subscriptions and display live channels.
